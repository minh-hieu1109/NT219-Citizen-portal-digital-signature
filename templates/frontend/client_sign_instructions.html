Request #{{ signing_request.id }} · {{ signing_request.document.title }}

What this step does

  1. The portal prepares PAdES signed attributes for this request.
  2. The local signer app fetches the pending session using the short-lived token.
  3. The local signer signs with the citizen private key.
  4. The portal verifies the ML-DSA signature with the public certificate.
  5. If valid, the portal embeds the signature into the PDF.

Run the local signer

python client-signer-local/client_signer_gui.py

Paste the token shown on the signing request detail page into the local signer app. Do not share this token. It is not the private key, but it grants temporary access to this signing session.
